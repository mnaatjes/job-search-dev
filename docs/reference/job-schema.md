# Job Data Schema and Field Definitions

This reference specifies the tabular schema and Pydantic models generated by the intake pipeline.

## Tabular Output Schema

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `site` | `str` | Target job board (`indeed`, `linkedin`, `zip_recruiter`, `glassdoor`, `google`) |
| `title` | `str` | Normalized job title |
| `company` | `str` | Employer/Company name |
| `city` | `str` | City location if detected |
| `state` | `str` | State/Region code |
| `country` | `str` | Country identifier |
| `location` | `str` | Raw location string |
| `job_type` | `str` | `fulltime`, `parttime`, `contract`, `internship` |
| `interval` | `str` | Compensation interval (`yearly`, `monthly`, `hourly`) |
| `min_amount` | `float` | Minimum compensation floor |
| `max_amount` | `float` | Maximum compensation ceiling |
| `currency` | `str` | Currency ISO code (`USD`, `EUR`, etc.) |
| `is_remote` | `bool` | Boolean flag indicating remote work |
| `job_url` | `str` | Direct posting URL |
| `description` | `str` | Markdown-rendered body text of the job description |
| `date_posted` | `date` | Published timestamp or date |
| `emails` | `list[str]` | Detected contact emails in posting body |
